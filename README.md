# csv_build — 수행평가 별명 검색 프로그램 생성기

수행평가 CSV 파일을 넣으면, **별명을 정확히 입력했을 때만 그 학생의 결과를 보여 주는 검색 프로그램(.py)** 을 만들어 주는 도구입니다.

학생들에게 점수와 세특 내용을 공개할 때, 각자 자기 별명으로 자기 결과만 확인하게 하고 싶을 때 쓰면 됩니다.

## 주요 기능

- **CSV 미리보기**: CSV를 열면 내용이 표로 나옵니다.
- **CONVERT 한 번으로 생성**: 과목명을 입력하고 버튼을 누르면 검색 프로그램이 만들어집니다.
- **별명 검색 전용**: 정확히 일치하는 별명을 입력해야만 그 행이 열이름과 함께 표로 나옵니다. 일치하지 않으면 오류를 보여 줍니다.
- **내용 보호**: 생성된 프로그램에 CSV 내용이 모두 들어 있지만 학생별로 암호화되어 있습니다. 검색 말고는 내용을 볼 방법이 없습니다.
- **난독화**: 생성된 `.py` 파일을 열어 보면 알아볼 수 없는 문자열만 보입니다.
- **한글 지원**: UTF-8과 엑셀에서 저장한 CP949(EUC-KR) CSV를 모두 자동으로 인식합니다.
- **보기 좋은 화면**: 창 너비는 1024px입니다. 세특 열은 자동으로 줄바꿈되고, 나머지 열은 내용 길이에 맞춰 좁아져 가로 스크롤 없이 볼 수 있습니다.
- **추가 설치 없음**: Python 표준 라이브러리(tkinter 포함)만 사용합니다.

## 준비물

- Python 3.8 이상
  - Windows/macOS에서 [python.org](https://www.python.org/) 설치본을 쓰면 tkinter가 포함되어 있습니다.
  - Ubuntu 등 리눅스는 `sudo apt install python3-tk` 로 tkinter를 따로 설치해야 합니다.

## CSV 파일 형식

첫 행은 **열이름**이고, 두 번째 행부터 학생 데이터입니다.

```csv
학년,반,번호,이름,별명,수행1,수행2,수행3,총점,세특
11,1,4,김준서,몽키매직,32,18,40,90,"세특 내용..."
```

- 열이름이 정확히 **`별명`** 인 열이 반드시 있어야 하고, 이 열로 검색합니다.
- 열이름에 **`세특`** 이 들어간 열(예: `세특`, `세특내용`)은 자동 줄바꿈으로 표시합니다. 해당 열이 없으면 마지막 열을 줄바꿈합니다.
- 수행평가 열이 몇 개든 상관없습니다. 열 구성은 첫 행을 보고 판단합니다.
- 별명이 비어 있는 행은 제외됩니다. 같은 별명이 여러 행에 있으면 검색할 때 함께 표시됩니다.

## 사용법

### 1. 창 화면으로 사용

```bash
python csv_build.py
```

1. **[CSV 열기]** 를 눌러 CSV 파일을 고르면 내용이 표로 나옵니다.
2. **과목명** 칸에 과목명을 입력합니다. 이 과목명이 생성된 프로그램의 창 이름이 됩니다.
3. **[CONVERT]** 를 누르고 저장 위치를 고르면 검색 프로그램이 만들어집니다.

CSV를 미리 지정해서 창을 열 수도 있습니다.

```bash
python csv_build.py aa.csv --gui
```

### 2. 명령줄로 사용

```bash
python csv_build.py aa.csv
```

과목명을 물어본 뒤 같은 폴더에 `aa_search.py` 를 만듭니다.

| 옵션 | 설명 | 예시 |
|---|---|---|
| `-s`, `--subject` | 과목명(창 이름)을 바로 지정 | `-s 빅데이터분석` |
| `-o` | 생성할 파일 이름 지정 | `-o 결과.py` |
| `--gui` | 창 화면으로 열기 | `--gui` |

```bash
python csv_build.py aa.csv -s 빅데이터분석 -o 빅데이터_검색.py
```

### 3. 생성된 검색 프로그램 실행

```bash
python aa_search.py
```

Windows에서는 파일을 더블클릭해도 실행됩니다. 별명을 입력하고 **Enter** 를 누르거나 **[검색]** 을 누르면 결과가 나옵니다.

- 대소문자를 구분합니다. 예를 들어 `jhjh` 는 검색되지만 `JHJH` 는 오류가 납니다.
- 앞뒤 공백은 무시합니다.
- 일부만 맞는 별명(예: `구원찬` 대신 `구원`)은 검색되지 않습니다.

## 보안 방식

| 단계 | 내용 |
|---|---|
| 학생별 암호화 | 각 학생의 행과 열이름을 **그 학생의 별명으로 만든 키**(PBKDF2-SHA256, 120,000회)로 암호화합니다. 별명을 모르면 복호화할 수 없습니다. |
| 무결성 확인 | HMAC-SHA256으로 데이터가 바뀌지 않았는지 확인합니다. |
| 학생 수 숨김 | 가짜 항목을 섞어 넣어 몇 명의 데이터가 들어 있는지 알 수 없게 합니다. |
| 파일 난독화 | 프로그램 전체를 zlib 압축 → XOR → Base85로 감싸서, 파일을 열어도 내용을 알아볼 수 없습니다. |

### 주의할 점

- **별명은 짐작하기 어렵게 정하세요.** 별명이 학생 이름과 같으면 이름을 아는 사람은 누구나 검색할 수 있습니다. 검색 한 번에 약 0.1초가 걸리게 해서 무작위 대입을 늦추지만, 쉬운 별명은 막을 수 없습니다.
- **원본 CSV와 생성된 프로그램은 GitHub에 올리지 마세요.** 원본 CSV에는 학생 개인정보가 그대로 들어 있습니다. 아래처럼 `.gitignore` 에 추가해 두면 실수로 올라가는 것을 막을 수 있습니다.

```gitignore
*.csv
*_search.py
```

## 동작 원리 (요약)

1. CSV를 읽어 `별명` 열을 찾습니다.
2. 별명별로 행을 묶어, 별명에서 만든 키로 각각 암호화합니다.
3. 암호화된 데이터와 검색 화면 코드를 하나의 프로그램으로 합칩니다.
4. 합친 프로그램을 난독화해 `.py` 파일로 저장합니다.
5. 검색 프로그램은 입력한 별명으로 키를 만들어 해당 데이터를 찾고, 풀리면 표로 보여 줍니다.
